# Portfolio

## Overview

The goal of this software was to demonstrate my skills in the different areas I have had the opportunity to explore throughout my career. This included building an application with Angular and demonstrating my ability to deploy several projects: this portfolio, the Procurement Calendar, and the inventory management application.

Other, less visible aspects also required learning, even for this short project. These included configuring a network to securely expose each of my services to other devices on my network.

In short, I wanted to create a small project that would showcase the skills I have developed so far.

## Features

- Convert a Markdown file into a web page.
- Link to demonstrations of the featured projects.
